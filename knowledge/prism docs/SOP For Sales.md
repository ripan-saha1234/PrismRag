Customer LTV (lifetime value) measurement: (part of account management strategy)

Must focus on retaining a customer's LTV for a more profitable and sustainable business model

If Project-Based:

LTV = Initial Project Value + All Repeat Projects + All Upsells

If Retainer-Based:

LTV = Average Monthly Revenue × Client Duration (in months)

If Hybrid Model (Most Accurate for You)

LTV = (Total Project Revenue) + (Recurring Revenue × Duration)
